# How I'd approach AI adoption at a large UK charity (interactive sample)

**Live page:** https://saeedfzn.github.io/charity-ai-adoption-demo/

A single-page, interactive sketch by Faizaan Saeed, built for a Change and Adoption Manager (AI) application. It shows how I'd approach AI and Microsoft Copilot adoption in a large UK charity:

1. **Change impact and readiness:** six colleague groups typical of a large charity, with an impact slider, five ADKAR readiness sliders, a calculated support priority and a suggested starting point at the barrier point (the first ADKAR element, in order, scoring 3 or below).
2. **Barrier diagnosis:** seven common barriers, each with a likely ADKAR gap, a likely cause, a targeted intervention, a key message, an owner and a measure.
3. **Intervention plan:** communications, engagement, learning, coaching, a champions network and practical resources across pilot, scale and sustain phases, with exit criteria for each.
4. **Measuring adoption:** leading and lagging indicators, an illustrative dashboard by group and month, and a "you said, we did" loop.
5. **Responsible AI:** supporter data, health data as special category data under UK GDPR, safeguarding, checking outputs, the Code of Fundraising Practice and Copilot permissions hygiene, plus a short quick check.
6. **The approach in five slides:** "AI adoption in the first six months", with speaker notes.

It closes with a short statement of what I bring.

Plain HTML, CSS and JavaScript in one file, with no dependencies. It has a light and dark theme, works at phone width and can be used with a keyboard.

**Important:** all groups, scores and figures are illustrative. This is an independent sample that isn't based on any internal information, and it is not affiliated with or endorsed by the British Heart Foundation. Nothing here is legal, data protection or fundraising compliance advice.
